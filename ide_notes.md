# Git в VS Code: заметки

## Что удобно делать в VS Code

1. Панель Source Control сразу показывает изменённые, подготовленные и неотслеживаемые файлы.
2. Встроенный diff наглядно выделяет добавленные и удалённые строки, поэтому изменения легко проверить до коммита.
3. История и GitLens помогают увидеть автора и время изменения каждой строки, не переключаясь в терминал.

## Что удобнее делать в терминале

Сложные операции с историей, например интерактивный rebase, удобнее выполнять в терминале: команды явно показывают порядок действий и подходят для автоматизации.
